# rose-and-Rome

14 child books

This repository collects the draft text for the "Rose and Rome" children's series. Completed drafts so far:

- Book 1 — The North Star Promise (Mentalism + safety anchor)
- Book 2 — The Lantern Rule (Cause & Effect + boundaries)
- Book 3 — The Quiet House Map (Correspondence + noticing patterns)

Each draft lives in `books/` as a standalone markdown file.
